Console setup

Set your console's proxy server to:

  • PS5: Settings › Network › Settings › Set Up Internet Connection. Highlight your network, press Options, choose Advanced Settings › Proxy Server › Use.
  • PS4: Settings › Network › Set Up Internet Connection › Custom. Keep the defaults until Proxy Server › Use.
